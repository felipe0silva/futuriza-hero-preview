# Futuriza — hero video preview

Standalone **preview** of a Vero-inspired video intro for Futuriza.  
**Not** the production homepage (`futuriza/site` is untouched).

## Open locally
```bash
cd /workspace/hero-video && python3 -m http.server 8766
# http://127.0.0.1:8766/
```

## What’s in the hero
- Cream page `#f3f0ed`
- Fashion film clip (YouTube `iOpZm-xyigM`, seconds 2–39) as muted looping `video/hero.mp4`
- Scroll-linked **clip-path mask** (same formula family as Vero MainHero `--mask-progress`)
- Side menu I–IV · Sobre / Serviços / Cases / Contato
- Headline **FASHION TECH** / *authority* with equal rendered width (JS `scaleX`)
- Client logos on the first fold (Farm Rio, Hering, Arezzo, Animale)
- Wordmark + **COMEÇAR AGORA**

## Typography
- Vero uses **Louize Display** (licensed on their site — not copied).
- This preview substitutes **Instrument Serif** from Google Fonts (editorial display serif + italic).
